## 高优先级安全要求

- 绿色查询自动执行；黄色写操作展示服务端确认摘要；红色操作使用 Passkey（要求 User Verification）或已验证绑定手机的短信验证码。交易密码不满足红色强验证。
- 确认时在用户执行租约内重新采集日累计、频率、收款人和账户锁定事实，风险只能升级。兼容卡片工具也不能绕过挂失/解锁/调额红色策略。
- 短信挑战绑定用户与动作，或绑定要修改的新密码；五分钟有效、单次消费、最多五次尝试、限制发送频率。连续强验证失败触发30分钟账户锁定。未设置密码的用户没有默认密码兜底。
- 资金路径使用数据库事务和条件余额/本金更新。AA 不允许收款人或后台代造入账；投资补偿仅冲正本操作流水，不能重复退款。
- 新版定时任务将结算与成功状态原子提交；中断恢复作废孤儿确认单，未授权旧任务须重新核对。没有可靠标记的旧版 processing 任务必须人工核查，不能直接重跑。
- 工具结果清洗、参数白名单、只读生成式 UI、用户身份闭包与不可由模型调用的确认入口共同限制注入影响。模型正文发送前核验金额与成功陈述，客户端提交的历史工具输出不作为银行凭证。
- 关键决策、确认、执行、补偿及人工控制写入哈希审计链。网页和 worker 的前序读取与日志追加在同一数据库事务，跨进程锁冲突限时重试；事务内不得包含网络或其他外部副作用。
- 生成代码仍在 QuickJS 沙箱内执行，受时间/内存/输出限制；没有网络、文件系统或任意银行写操作能力。
- 生产启用 CSRF 与认证限流，签名密钥要求至少32位独立随机值；非本地或生产后台要求独立 `ADMIN_TOKEN`。该令牌属于演示访问控制，后续生产应增加管理员角色和细粒度权限。

## 任务规划与接管

自然语言经模型工具循环处理，复杂任务提交 DAG 并校验依赖及工具白名单。任务中心支持暂停、恢复、取消与逆序尝试补偿；Web、H5 和飞书共用确认恢复入口。人工节点支持记录处理后继续；无法回退的失败计划停止，允许记录人工核对结果，人工备注不能替代银行执行回执。

## 验收与外部配置

- 回归覆盖风险升级、兼容工具权限、并发申购/赎回、短信归属/过期/重放/密码参数绑定、卡申请及授信下限、AA 双边账、预算预留/释放、任务中断及孤儿确认、DAG 暂停恢复、输出流阻断、双进程审计链等。使用独立 `.scratch` 数据库，不清空用户库。
- 真实 DeepSeek 已联调账单分类图、新卡申请、确认后的只读回执核对、生日与 AA 查询。移动端已检查四卡更新、独立账单、新卡申请及强验证入口。
- 短信：配置 `SMS_DELIVERY_URL`，服务接收 `POST {phoneNumber,code,expiresInSeconds,purpose}` 并在成功发送后返回2xx；可用 `SMS_DELIVERY_TOKEN` 认证。红色操作没有日志验证码替代。实际服务商投递尚需外部验收。
- Passkey：在安全设置由用户实际设备注册；域名须与 `PUBLIC_BASE_URL` 对应。没有替用户完成真实生物识别验收。
- 飞书：需配置应用凭据、权限及渠道绑定。共享确认恢复服务已回归，真实机器人回调与卡片交互须在已配置应用中验收。
- 生日商户、外部银行转账和信用授信是模拟；不能当成真实商业履约。
- 多实例部署仍需共享会话展示快照、Passkey challenge 和飞书历史；真实客服工单、模型故障自动切换、独立空闲超时策略属于后续生产化范围。规则和数字校验不能证明所有输入下绝无幻觉，提交前仍需对抗用例与完整演示录屏。

本地运行：根目录 `start.bat` 同时启动网页与自动任务并打开实时日志。详情见 [DEVELOPMENT.md](DEVELOPMENT.md)。
